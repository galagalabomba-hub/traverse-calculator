免 Python 將此網頁打包為 Windows EXE 執行檔

本應用程式為完全自包含的標準 HTML5/JS 系統。完全不需 Python 環境，即可透過以下 Windows 原生或綠色工具打包為雙擊可執行的 .exe 檔：

方法一：MS Edge App 快捷捷徑 (最推薦，零安裝)

利用 Windows 內建 Microsoft Edge 核心產生如同獨立軟體的視窗：

  1. 雙擊開啟本 traverse_calculator.html 檔案。
  2. 點擊 Edge 瀏覽器右上角「...」選單 ➔ 應用程式 (Apps) ➔ 將此網站作為應用程式安裝。
  3. 安裝後會自動在桌面生成獨立圖示與原生 GUI 視窗，運作與普通 EXE 完全無異！

方法二：Web2EXE / HTML Executable (圖形化綠色封裝)

  1. 下載免安裝軟體 Web2EXE 或 HTML Executable。
  2. 選擇本 traverse_calculator.html 作為 Home / Main Page。
  3. 點擊「Build / Export EXE」即可輸出單一獨立 .exe 檔，可拷貝至任何 Windows 電腦執行。

方法三：NW.js / Nativefier (極致原生體驗)

使用 Node.js 指令打包為獨立視窗：

npx nativefier --name "閉合導線計算器" "file:///C:/path/to/traverse_calculator.html"
